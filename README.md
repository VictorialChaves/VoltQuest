VoltQuest ⚡🤖

Bem-vindo ao VoltQuest, um simulador educativo interativo desenvolvido para ensinar conceitos de eletrônica, circuitos e automação de forma prática e gamificada!

🎯 Sobre o Projeto

O VoltQuest transforma a tela do computador num laboratório de engenharia. Através de um sistema intuitivo de Drag & Drop (Arrastar e Soltar) com feedback magnético, os jogadores aprendem montando sistemas reais, desde circuitos básicos até robôs complexos. O objetivo é conectar a teoria acadêmica à prática visual e interativa.

🚀 Fases e Funcionalidades

O jogo está dividido em três níveis de complexidade:

Fase 1: A Bancada (Fundamentos): Introdução à protoboard, fluxo de energia, resistores, LEDs e interruptores. Inclui simulação de curto-circuito (explosão do LED) em caso de montagem incorreta.
Fase 2: Carrinho Seguidor de Linha (Automação): Montagem de um robô móvel utilizando Motores DC e Sensores LDR. Ensina a importância do posicionamento dos componentes para a lógica de navegação.
Fase 3: O Robô Bípede (Sistemas Complexos): Desafio final de montagem estrutural e integração com o Microcontrolador (o "cérebro"). Apresenta uma transformação visual completa e física de movimento.

Destaques:

Sistema de dicas contextuais (Lâmpada Inteligente).
Interface (UI) responsiva com menu de opções e controle de volume global (Mesa de Som).
Feedbacks sonoros (Game Feel) em todos os encaixes e interações mecânicas.

🛠️ Tecnologias Utilizadas

Motor Gráfico (Engine): Godot Engine 4.x
Linguagem de Programação: GDScript
Design de Interface e Arte: Canva e Inkscape

Áudio: Efeitos de interface e Game Juice (SFX/BGM)

🎮 Como Jogar (Instalação e Uso)

Não é necessário ter o Godot instalado para jogar! Basta seguir os passos abaixo:
Acesse a aba Releases deste repositório.
Faça o download do arquivo compactado mais recente (ex: VoltQuest_v1.0.zip).
Extraia o arquivo numa pasta no seu computador.
Execute o arquivo VoltQuest.exe.
Uso: Use o botão esquerdo do mouse para clicar, segurar e arrastar os componentes. Solte-os próximos aos "buracos" corretos (marcadores) para encaixar. Dê um duplo clique no interruptor para ligá-lo.
